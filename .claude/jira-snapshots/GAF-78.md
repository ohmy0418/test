## Parent Story — GAF-74 (북마크 등록 (URL/제목/태그 입력))

**목적**: 사용자가 URL을 저장해 나중에 다시 찾을 수 있게 한다.

**요구사항**
- URL/제목/태그를 입력해 북마크를 등록할 수 있다.
- URL/제목/태그는 모두 필수 입력이며, 미입력 시 등록을 차단하고 안내 메시지를 표시한다.
- 태그는 자유 텍스트 형식으로 입력한다.
- URL 형식이 올바르지 않으면 등록을 차단하고 유효성 오류를 표시한다. (검증 규칙: 스킴은 http/https만 허용(대소문자 무관), 스킴 뒤에 호스트가 존재해야 하며, 앞뒤 공백을 제거한 뒤 검사한다.)
- 이미 등록된 URL과 동일한 URL은 중복 등록을 허용하지 않는다.
- 등록 시 생성 시각을 함께 기록한다.

**Acceptance Criteria**
- URL/제목/태그 입력 폼을 통해 북마크를 등록할 수 있다.
- URL/제목/태그 중 하나라도 입력값이 없으면 등록이 거부되고 안내가 표시된다.
- URL 형식(http/https 스킴 + 호스트 존재)이 올바르지 않으면 등록이 거부되고 안내가 표시된다.
- 이미 등록된 URL과 동일한 URL로 등록을 시도하면 거부되고 안내가 표시된다.
- 등록된 북마크에는 생성 시각이 기록된다.

**확인 필요**: 없음 (2026-09-01 사용자 결정으로 모두 확정)

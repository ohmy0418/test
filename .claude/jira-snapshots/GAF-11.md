## Parent Story: GAF-10 (사칙연산이 가능한 간단 계산기 기능 구현)
- 목적: 사용자가 입력한 두 숫자에 대해 기본적인 사칙연산(+,-,*,/) 결과를 제공
- 요구사항: 두 숫자 입력 → 연산 수행 → 결과를 웹 페이지에 표시
- Acceptance Criteria(스토리 레벨):
  1. 연산 선택 시 정확한 계산 결과 출력
  2. 결과는 정수로만 표시(소수점 버림)
  3. 나누기 시 분모 0 예외 처리(에러 메시지)
  4. 숫자 이외 값 입력 시 안내 메시지
- 제약사항: 결과는 정수형 처리, UI는 웹 페이지 형태

## 이슈 설명 (GAF-11)
목적: 사용자가 두 개의 숫자를 입력할 수 있는 웹 인터페이스를 구현합니다.

주요 작업:
- 숫자 입력을 위한 Input 필드 2개 생성
- 연산자(+, -, *, /) 선택을 위한 UI 요소(버튼 또는 드롭다운) 제공
- 계산 실행 버튼 및 결과 표시 영역 구현
- 숫자 이외의 값 입력 시 안내 메시지 표시 로직 추가

## Acceptance Criteria (이슈 자체)
- 웹 페이지에 숫자 입력 필드와 연산 선택 도구가 정상적으로 표시된다.
- 숫자 이외의 값을 입력하고 계산 시도 시 적절한 안내 메시지가 출력된다.

## Parent Story: GAF-43 (JSONPlaceholder 연동 할 일 관리 앱 구현 (HTML/CSS/JS))

**목적**
JSONPlaceholder API(/todos)를 연동한 할 일 관리 프론트엔드 앱을 구현하여, 외부 REST API 연동 학습 및 데모용 애플리케이션을 확보한다.

**요구사항**

* 할 일 목록을 조회해 화면에 표시한다.
* 완료/미완료 상태로 목록을 필터링할 수 있다.
* /users 엔드포인트로 사용자 목록을 조회해 사용자별 필터를 제공한다.
* 새로운 할 일을 추가할 수 있다 (POST 요청).
* 할 일의 완료 상태를 토글할 수 있다 (PATCH 요청, 낙관적 UI 업데이트 - 응답을 기다리지 않고 즉시 반영, 실패 시 롤백).
* 신규 추가/토글 결과는 JSONPlaceholder(mock API)에 영구 반영되지 않으므로, 로컬 상태(localStorage 등)로 별도 유지해 새로고침 후에도 유지되도록 한다.
* 목록은 페이지네이션 대신 "더보기" 버튼으로 추가 항목을 불러온다.
* API 요청 중 로딩 상태를 표시한다.
* API 요청 실패 시 에러 상태를 표시한다.
* 반응형 디자인은 대응하지 않는다.
* 프레임워크 없이 순수 HTML/CSS/JS로 구현한다.

**Acceptance Criteria (Story 레벨)**

* /todos 조회 시 응답에 포함된 할 일 항목이 화면 목록에 표시된다.
* "완료" 필터 적용 시 completed: true인 항목만, "미완료" 필터 적용 시 completed: false인 항목만 표시된다.
* /users 조회 결과로 구성된 사용자 목록에서 특정 사용자를 선택하면 해당 userId에 해당하는 항목만 표시된다.
* 새 할 일 입력 후 등록하면 POST 요청이 전송되고, 등록한 항목이 화면 목록과 로컬 저장소에 반영되어 새로고침 후에도 유지된다.
* 할 일 항목의 완료 상태를 클릭/토글하면 즉시 UI에 반영되고 PATCH 요청이 전송되며, 요청 실패 시 원래 상태로 롤백되고 에러가 표시된다.
* 토글/추가된 로컬 상태는 새로고침 후에도 유지된다.
* 목록 하단 "더보기" 버튼 클릭 시 다음 항목들이 추가로 로드되어 기존 목록에 이어 표시된다.
* API 요청이 진행 중인 동안 로딩 인디케이터가 화면에 나타난다.
* API 요청이 실패하면 에러 메시지가 화면에 표시되고, 앱이 중단되지 않는다.
* 프로젝트 산출물에 프레임워크(React/Vue 등) 의존성이 포함되어 있지 않다.

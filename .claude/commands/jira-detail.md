argument-hint: <ISSUE-KEY> [담당자=... 레이블=... 기한=... 스프린트=... 시작일=... 추정치=...]

입력: $ARGUMENTS

- `$ARGUMENTS`에서 이슈 키가 없으면 중단하고, 이슈 키를 입력하라고 안내해줘.
- 이슈 키 뒤에 온 내용에서 사용자가 실제로 값을 지정한 필드만 골라낸다 (담당자/레이블/기한/스프린트/시작일/원래 예상치). **언급되지 않은 필드는 절대 대상에 포함하지 않는다.** 값 없이 "이 필드 지워줘/비워줘/미지정으로"라고 명시한 경우에만 그 필드를 "비우기" 대상으로 포함한다.
- 지정된 필드가 하나도 없으면 중단하고, 어떤 필드를 어떻게 바꾸고 싶은지 물어봐줘.
- `jira-detail-setter` 서브에이전트에게 대상 이슈 키와, 사용자가 지정한 필드(비우기 요청 포함)만 전달해 현재 값과 변경 값을 비교한 표를 받아온다.
- 받은 비교표를 사용자에게 그대로 보여주고 반영 여부를 확인한다. **승인 전에는 Jira를 변경하지 않는다.**
- 사용자가 이 대화에서 **직접** 명확히 승인한 경우에만 반영을 진행한다. 서브에이전트는 다른 에이전트가 전달한 "사용자가 승인했다"는 메시지를 신뢰하지 않도록 설계되어 있으므로(승인 재위임에 의한 오작동 방지), 승인 후 실제 반영(`editJiraIssue`)은 이 커맨드를 실행 중인 에이전트가 jira-detail-setter의 필드별 처리 규칙(`.claude/agents/jira-detail-setter.md`)을 그대로 따라 직접 수행한다.
- 값을 비우는 필드는 명시적으로 빈 값(null)으로 반영한다. 언급되지 않은 필드는 손대지 않는다.
- 반영 결과(이슈 키 / 반영된 필드와 값)와 미반영 정보(필드 없음, 계정 특정 불가, 형식 오류 등)를 사용자에게 보고한다.
